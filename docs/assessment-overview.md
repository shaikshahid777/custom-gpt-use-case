# Assessment Overview

## Topic
Introduction to Custom GPTs — Use Case Definition

## Selected Use Case
**AI Job Application Assistant**

## Problem
Entry-level job seekers repeatedly analyze job descriptions, identify relevant skills, tailor resumes, and prepare application responses. Performing these tasks manually is repetitive and can lead to generic applications, missed requirements, and inconsistent application quality.

## Expected Outcomes
1. Reduce job-description analysis time.
2. Generate structured skill-match and skill-gap analysis.
3. Suggest tailored resume bullet points based on actual user experience.
4. Generate customized application responses or cover-letter drafts.
5. Provide a final pre-submission checklist.

## Validation

### Clarity
The problem, target users, and expected outputs are clearly defined.

### Relevance
The use case addresses recurring application-preparation work for students and entry-level job seekers.

### Feasibility
The use case can be implemented with standard Custom GPT instructions, reference material, and conversational interaction.
