# Demo Guide

## Demonstration Scenario

A sample AI Automation Intern job description is provided to the GPT.

### Sample requirements
- n8n
- REST APIs
- Webhooks
- JSON
- AI tools
- Basic Python
- API integrations
- Workflow troubleshooting

## Expected GPT Behavior

The GPT should:
1. Extract the required skills.
2. Summarize responsibilities.
3. Identify skills the user should demonstrate.
4. Identify potential skill gaps without claiming they are actual gaps unless the user's background is known.
5. Avoid inventing experience.
6. Provide structured resume-bullet guidance.
7. Provide a pre-submission checklist.
